# P0 实现与验收状态

记录日期：2026-10-18。依据 `PRD.md` v0.4、`ARCHITECTURE.md` v0.1、`DESIGN.md` v0.2。

**当前是可编译的开发实现，不能视为 P0 已交付或已通过发布验收。** 单元测试证明所覆盖的局部行为；没有 Ubuntu 工作站/VPS、完整 gVisor 配置、真实 Codex OAuth 与 ChatGPT 账户的运行证据。下面同时列出代码已有的能力与实际缺失功能，不能把缺失功能全部归结为“尚未在 Linux 测试”。

## 已有实现与自动化检查

- Rust Cargo workspace，独立 `orc-mcp`、`orc-endpoint`、`orc-runner`、`orc-watchdog` 与 `orc`。
- 领域身份、grant、两种环境/三种策略、规则优先级、严格 JSON、重复键拒绝、UUIDv7 时窗、规范化整数请求摘要、签名信封和能力校验。
- SQLite 独立工作线程、有界控制/普通队列、提交去重、审批单次消费、CAS 任务状态、撤销、备份、安全 journal 链及旧库恢复测试。
- OAuth 客户端登记、PKCE、资源绑定、本地所有者同意、令牌轮换及重用检测；MCP Streamable HTTP 服务和身份传递；终端出站 mTLS/WebSocket、身份签名、连接代数及撤销同步。
- Linux systemd 宿主适配器、固定实例/启动标记/runner、gVisor 专用 rootless 配置检查与 fail-closed 后端、独立停止 watchdog。macOS 不冒充 Linux 执行后端。
- 内容寻址文本对象、限量快照、链接与特殊文件拒绝、秘密文件名排除、固定目录 FD 访问、差异、受管目录锁、基线冲突、逐文件回写结果及禁止批次重放。
- 本地 UID 检查管理 socket、CLI、角色初始化、私有状态目录、签名离线包校验及安装、角色升级/回退/卸载、初步诊断。
- 十分钟签名登记请求/邀请、设备签名兑换与数据库原子消费；终态任务正文到期清理、安全事实保留；持锁前台编辑器入口。

本机（macOS arm64、Rust 1.99.1）已执行 `cargo fmt --all --check`、`cargo clippy --workspace --all-targets --locked --offline -- -D warnings` 和 `cargo test --workspace --locked --offline`：**124 项测试通过，0 失败**；`cargo build --workspace --release --locked --offline` 成功且无警告。回环网络测试使用真实 mTLS/WebSocket；Linux 专用测试在当前宿主不执行，已安排 Ubuntu CI。精确记录见 [local-checks.json](local-checks.json)。

## 尚未完成的交付内容

1. **发布与便利安装**：没有已签名的公开发行包、可信发布公钥渠道、在线下载入口或完整交互向导。`setup` 可生成角色配置；TLS 和对端身份仍由所有者准备。签名初装与升级/回退/卸载已实现；尚缺真实 Linux systemd 切换、多个正式版本和非作者安装证据。源码普通文件安装不会被维护器静默接管。
2. **设备登记生命周期**：已实现双方身份签名/证书固定、十分钟一次性邀请和事务兑换；内嵌 CA 签发、证书续签和旧身份连续性证明流程未完成。登记与执行 grant 分离，仍不是完整 FR-02 证书生命周期。
3. **撤销与维护**：本地持久撤销、持久连接代数/服务版本和重连撤销同步已有，控制队列满时关闭连接强制重新同步；已有逐设备持久撤销 outbox、确认版本和送达状态查询；ACK 表示持久接收而非进程停止。已有维护暂停、在途/未知拒绝、SQLite 备份、停止核实和角色服务切换；混合版本发布矩阵及这些流程的真实 systemd 运行证据仍缺。
4. **隔离发行环境**：没有可直接分发的固定 Python 工具镜像、镜像摘要、实际 runsc/cgroup/UID 映射验收结果。gVisor 后端要求匹配验证记录，缺条件拒绝执行；不能把填写验证 JSON 当作运行证据。三类样例的隔离端到端验收仍缺。
5. **存储生命周期与容量**：已实现单对象/请求/输出等预算及安全 journal 上限；已有终态任务正文 24 小时清理及 journal 防止旧库复活；已有对象可达性保护和宽限 GC、数据库/journal 各 256 MiB 硬上限和 192 MiB 高水位控制余量、七天/128 MiB 元数据审计预算；完整任务容量预留与诊断包导出/清理尚不完整；列表 cursor 分页也未形成完整契约，过大响应会拒绝。读取过期后拒绝不等于磁盘正文已经删除。
6. **受管编辑**：已有新建受管工作区、锁和 `orc workspace edit` 直接 argv 前台编辑器入口。只支持遵守排他写入约定的目录；普通项目不能声明自动回写安全。新建深层目录、非 UTF-8 文件名和跨文件原子性不在当前实现保证内。
7. **设计适配差异**：宿主/systemd 与 Docker 控制当前使用固定参数 CLI 适配；设计的 zbus/Bollard 适配尚未替换和验证。不能据此宣称已完成原定依赖组合 M0。
8. **真实客户端与网络**：没有真实 Codex/ChatGPT 登录、至少两台独立 Ubuntu、仅出站防火墙、云端入口、邻接版本或非作者安装记录。Skill 文件存在不等于客户端已安装或可访问 MCP。
